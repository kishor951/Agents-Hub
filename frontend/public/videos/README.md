# Video Assets

Place your video meme files in this directory.

## Supported formats:
- MP4 (recommended)
- WebM
- OGG

## Usage:
The videos will be accessed via `/videos/your-video-name.mp4` in the application.

## Example:
Place a file named `agent-meme.mp4` here, and it will be accessible at `/videos/agent-meme.mp4`
